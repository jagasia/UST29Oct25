SQL
------
	Structured Query Language


is used to access a database in terms of
	adding record(s)
	updating records
	deleting records
	querying records from one or more tables or views or relations
etc etc

DML	Data Manipulation Language
		INSERT
		UPDATE
		DELETE
		
DDL	Data Definition Language
		CREATE
		ALTER
		DROP
		TRUNCATE		

DQL	Data Query Language
		SELECT

DCL	Data Control Language
		GRANT
		REVOKE

TCL	Transaction Control Language
		COMMIT
		ROLLBACK
		SAVEPOINT

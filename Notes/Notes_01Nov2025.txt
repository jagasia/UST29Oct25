break
	The break statement breaks the execution of the current iteration of the loop. break exits the loop.

continue also breaks the current iteration of the loop. continue forces next iteration.





public class AppBreakContinue {

	public static void main(String[] args) {
		for(int i=0;i<10;i++) {
			if(i%2==0)
				continue;
			System.out.println(i);
		}
	}

}

Iterator
	is used to iterate/ traverse 
	traverse means, visit every element in the collection.
	
	Iterator can be used on List or Set

	But ListIterator is only for List			not for Set


	Iterator has only 3 methods:
		hasNext()		true if there is any more element to visit
		next()		returns the next element. And it consumes. 
		remove()		remove the current element

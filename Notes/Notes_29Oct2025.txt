JDK
	java development kit
		this is for the developers, to code, test

JRE
	java runtime environment
		this is for users, running the code


JVM
	JRE contains JVM. When we run the code, JVM will
		use JIT compiler to further compile the byte code into machine specific code and run.


Java compilation process:
	our java code is translated into byte code by javac
	while running the code, it is further translated from byte code into machine language code using JIT of JVM of JRE

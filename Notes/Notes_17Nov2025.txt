String is immutable. That means, we cannot change the contents of a String.

public class App2 {

	public static void main(String[] args) {
		String str="stationery";
		//can you replace e into a?
		str=str.replace('e', 'a');
		System.out.println(str);
	}

}


The above code looks like it is updating the contents. But not actually. It returns a new String and never updates the string itself.

Accept 2 strings from the user. Check if they are anagrams.

Anagrams are words made up of same set of characters, including the occurrence of those characters.

Ex:
	team
	meat

	tea
	eat

sort the chars and then check if they are equal



import java.util.Arrays;

public class AppAnagrams {

	public static void main(String[] args) {
		String str1="team";
		String str2="meta";
		
		//convert the string into char array
		char []arr1=str1.toCharArray();
		char []arr2=str2.toCharArray();
		
		Arrays.sort(arr1);
		Arrays.sort(arr2);
		
		String strSorted1=new String(arr1);
		String strSorted2=new String(arr2);
				
		System.out.println(Arrays.equals(arr1, arr2));
	}

}

public class Mathematics {
	private Integer no1;
	private Integer no2;
	private Float result=0.0f;
	
	public Mathematics() {}

	public Mathematics(Integer no1, Integer no2, Float result) {
		super();
		this.no1 = no1;
		this.no2 = no2;
		this.result = result;
	}

	public Integer getNo1() {
		return no1;
	}

	public void setNo1(Integer no1) {
		this.no1 = no1;
	}

	public Integer getNo2() {
		return no2;
	}

	public void setNo2(Integer no2) {
		this.no2 = no2;
	}

	public Float getResult() {
		return result;
	}

	public void setResult(Float result) {
		this.result = result;
	}
	
	public void addNumbers() {
		this.result=(float) (no1+no2);
	}
	
	public void multiplyNumbers() {
		result=((float)no1*no2);
	}
	
	
}

Below is a **clear, complete, step-by-step guide** on how to create a **JUnit 4 + Mockito** project from scratch **using Maven**, write a test, fix all errors, and run the test successfully in Eclipse / STS.

I’ll assume you want this setup:

# ✅ **STEP 1 — Create a New Maven Project**

### In Eclipse / Spring Tool Suite:

1. **File → New → Maven Project**
2. Check: **Create a simple project (skip archetype selection)** → **Next**
3. Enter:

   * **GroupId**: `com.ust.demo`
   * **ArtifactId**: `Shrisena`
   * Packaging: `jar`
4. Finish.

---

# ✅ **STEP 2 — Add Dependencies in pom.xml**

Replace the `<dependencies>` section with this:

```xml
<dependencies>

    <!-- JUnit 4 -->
    <dependency>
        <groupId>junit</groupId>
        <artifactId>junit</artifactId>
        <version>4.13.2</version>
        <scope>test</scope>
    </dependency>

    <!-- Mockito Core  -->
    <dependency>
        <groupId>org.mockito</groupId>
        <artifactId>mockito-core</artifactId>
        <version>5.8.0</version>
        <scope>test</scope>
    </dependency>

    <!-- Mockito JUnit 4 Runner -->
    <dependency>
        <groupId>org.mockito</groupId>
        <artifactId>mockito-junit-jupiter</artifactId>
        <version>5.8.0</version>
        <scope>test</scope>
    </dependency>

</dependencies>
```

### Then:

**Right-click project → Maven → Update Project (Alt+F5)**

---

# ✅ **STEP 3 — IMPORTANT: Ensure Eclipse Runs Tests Using JUnit 4**

To avoid the error:

> Cannot find org.junit.platform…Testable

Do this:

1. Right-click your test file → **Run As → Run Configurations**
2. Under **JUnit**, select your test run config
3. On the right, find **Test Runner**
4. Select **JUnit 4**
5. Apply → Run

This guarantees Eclipse won’t use JUnit 5.

---

# ✅ **STEP 4 — Create the Source Class**

Create file:

`src/main/java/com/ust/demo/MathsService.java`

```java
package com.ust.demo;

public class MathsService {

    public int sum(int i, int j) {
        return i + j;
    }

    public int difference(int i, int j) {
        return Math.abs(i - j);
    }
}
```

---

# ✅ **STEP 5 — Create the JUnit 4 + Mockito Test**

Create file:

`src/test/java/com/ust/demo/MathematicsTest.java`

```java
package com.ust.demo;

import static org.junit.Assert.assertEquals;
import static org.mockito.Mockito.when;

import org.junit.Test;
import org.junit.runner.RunWith;
import org.mockito.Mock;
import org.mockito.junit.MockitoJUnitRunner;

@RunWith(MockitoJUnitRunner.class)
public class MathematicsTest {

    @Mock
    MathsService proxy;

    @Test
    public void testSum() {
        when(proxy.sum(2, 3)).thenReturn(5);
        when(proxy.difference(2, 3)).thenReturn(1);

        assertEquals(5, proxy.sum(2, 3));
    }
}
```

✔ `@RunWith(MockitoJUnitRunner.class)` requires **JUnit 4**
✔ Mockito automatically initializes `@Mock`
✔ No null pointer errors

---

# ✅ **STEP 6 — Run the Test**

Right-click the file:
**MathematicsTest.java → Run As → JUnit Test**

Result should be:

```
Runs: 1   Errors: 0   Failures: 0
```

# 🧩 **If You Still See JUnit 5 Errors**

Add the JUnit 5 API to avoid IDE confusion:

```xml
<dependency>
    <groupId>org.junit.platform</groupId>
    <artifactId>junit-platform-launcher</artifactId>
    <version>1.10.0</version>
    <scope>test</scope>
</dependency>
```

This does **NOT** convert your test to JUnit 5 — it only removes IDE errors.
